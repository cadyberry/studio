# Palette — Color Intelligence for Creators

Extract, save, and organize color palettes from your artwork. Built for print-on-demand creators who need beautiful, print-ready color systems.

## What it does

- **Extract** — Drop any image, get a 5–6 color palette in seconds
- **Save & name** — Build a library of palettes from your art
- **Organize** — Group palettes into named collections (e.g. "Spring Drop", "Dark Academia")
- **Export** — PNG swatch strip, CSS variables, hex list, or JSON

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
