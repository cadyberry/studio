## Studio — Daily Update 2026-05-27

**What was built today:**

Two features shipped across two commits:

1. **CMYK print risk warning in the export modal** — before downloading a palette card, creators now see exactly which colors will shift in print, right in the export UI. Each swatch in the preview strip gets a colored risk dot (red = high ΔE, amber = caution), a ΔE tooltip animates in on swatch hover for precise shift values, and a warning banner shows a structured risk count ("2 high-risk · 1 caution"). The Download Palette Card action description also updates to surface flagged color counts at a glance. Risk simulation is memoized to avoid repeated color-science computation on re-renders.

2. **CSS stylesheet color extraction for URL import** — the `/api/extract-url-colors` route now follows `<link rel="stylesheet">` hrefs in fetched HTML and scans up to 5 linked CSS files in parallel (3s timeout each, errors silently skipped). Adds `hsl()` color parsing (both comma and modern space syntax), fixes the 3-digit hex regex to avoid false matches inside 6-digit codes, and returns a `cssCount` in the API response. The ImportModal surfaces an "HTML + N CSS" pill badge next to the detected-color count so Cady can see exactly which sources were mined.
