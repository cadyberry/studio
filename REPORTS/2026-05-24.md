## Studio — Daily Update 2026-05-24

**What was built today:**

Thirteen sessions shipped — a new single-day record. The throughline is keyboard power-user polish and library-intelligence features. In order:

- **Session 37 — Palette Card Keyboard Shortcuts:** Hover any card and fire actions without clicking. `D` dup, `F2` rename, `H` harmony, `L` lock/unlock, `Del` delete (two-press confirm). Shortcut hint strip appears in card footer on hover (`D dup · F2 name · H view · L lock · Del`), changes to `L unlock` when frozen. Ref-based handler mounted once to avoid stale closures and re-registration churn.

- **Session 38 — Search Shortcut (`/`):** Press `/` from anywhere (when not in an input) to jump focus to the search bar. RAF-deferred so color-search mode deactivates first. `Escape` clears and blurs. Inline `/` kbd hint appears in the empty search box; replaced by an `×` clear button when a query is active.

- **Session 39 — `?` Help Overlay:** Full keyboard shortcut reference sheet, accessible via `?` key or the header kbd button. Five groups (Global, Palette Card, Swatch Editor, Inline Rename, Tags), spring-animated modal enter/exit, scrollable body. `KeyboardHelpModal` is self-contained with its own Escape handler.

- **Session 40 — Sort by Most-Annotated + Interactive Collection Tooltip:** "Most annotated" added as a sort option. Collection sidebar tooltip converted from CSS-only hover to state-driven (onMouseEnter/Leave bridge), so the user can move onto the panel without it disappearing — and each palette row in the panel now has a **quick Duplicate button**. Age badge tooltip on palette cards now shows precise "Edited May 20, 2026 · Created May 15, 2026" via native `title`.

- **Session 41 — Inline Collection Rename + Jump-to-Collection Badge:** Double-click any collection name in the sidebar to rename in-place (Enter/blur commits, Escape cancels). The "in collection" chip on each palette card now shows the actual collection name and navigates to it on click — a genuine cross-panel navigation shortcut.

- **Session 42 — Palette Stats Panel:** Compact 2×3 grid widget in the left sidebar showing palettes count, total swatches, collections count, annotated %, top mood (with color dot), and oldest palette date. Appears when any palette exists; all stats derived live from the Zustand store.

- **Session 43 — Clear-Collection × + Collection Description Tooltip:** The "in collection" badge on each card gains a fade-in `×` on group-hover (red on hover, destructive, no modal) that clears the collection membership in one click. Collection sidebar names now show their description (if set) in the native title tooltip.

- **Session 44 — Empty Collection Indicator:** When a named collection has zero palettes, the library grid shows a styled placeholder with a violet→sky folder icon, a two-sentence affordance hint (with inline `<FolderOpen>` icon), and a "Browse all palettes" CTA — distinct branch from the generic no-results state.

- **Session 45 — Stats Panel Count-Up Animation:** The four numeric stats count up from 0 to their actual values on first mount with a 600ms ease-out cubic animation. Implemented as a reusable `AnimatedStat` component using `requestAnimationFrame`; `done` ref prevents re-triggering on subsequent renders.

- **Session 46 — Swatch Count Sparkline:** Third row added to the stats panel: a tiny 3-bar chart showing palette size distribution across small (1–4), medium (5–6), and large (7+) buckets. Violet→indigo→blue bars, proportional heights with a 3px floor, bucket labels below. Pure CSS (`flex-col justify-end`) over SVG.

- **Session 47 — Sidebar Flash on Jump-to-Collection:** Clicking the in-collection chip now flashes the matching sidebar row with a violet `rgba(139,92,246)` keyframe animation (750ms ease-out). CSS keyframe over Framer Motion — one-shot "fire and forget." `pointer-events: none` overlay so targets underneath are never blocked.

- **Session 48 — Palette Freshness Badge:** Color-coded age pill on each palette card for palettes created within the last 21 days. Emerald → lime → amber fade in both color and opacity as the palette ages; invisible at 21+ days. Uses `createdAt` (not `updatedAt`) — freshness tracks when a palette was born, not when it was last edited. Module-level pure function, no React coupling.

- **Session 49 — Tag Autocomplete:** Typing in the tag editor surfaces matching tags from across the entire library as a keyboard-navigable suggestion list. Substring match (not prefix), library-wide scope to prevent near-duplicates, full keyboard nav (↑↓ to move, Enter to select, Escape to dismiss), `onMouseDown` + `e.preventDefault()` to keep focus after click selection. Max 6 suggestions.
