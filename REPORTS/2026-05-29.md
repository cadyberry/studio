## Studio — Daily Update 2026-05-29

**What was built today:**

Two full feature sessions shipped:

**Session 60 — Color search history dropdown** — when the hex input is focused in color search mode, a floating dropdown lists the last 8 searched hex colors (most recent first), each with a color swatch preview. Clicking any item sets the search hex instantly. Supports full keyboard dismiss (Escape), a "Clear" button to wipe history, and deduplication (latest occurrence wins). Persisted to `localStorage` so the color vocabulary accumulates across page refreshes and revisits. Uses `mousedown` + `e.preventDefault()` on items (standard combobox pattern) so blur doesn't fire before the selection registers. Animated with Framer Motion `AnimatePresence`.

**Session 61 — Note excerpt preview in search + swatch ΔE tier label on hover** — two related polish improvements:
- When a text search query matches a palette's notes field, the card now shows a styled excerpt block (not just the plain italic notes line) with ~55 characters of context on each side of the match. Styled with a soft yellow background and a `StickyNote` icon. The matched text is highlighted with the same `bg-yellow-200` mark used for name highlights. A new pure helper `getNoteExcerpt()` returns `{ prefix, match, suffix }` so the highlight renders as JSX without innerHTML tricks.
- The ΔE badge on the best-matching swatch (e.g., "ΔE 14.3") now reveals its tier word on hover — "ΔE 14.3 · fair" — using `group-hover/swatch:inline` on a hidden span. Applied to both frozen-swatch and draggable-swatch code paths. Consistent with the info-row ΔE badge tooltip added in Session 59.

Both sessions: clean Turbopack build, zero TypeScript errors.
