## Studio — Daily Update 2026-05-30

**What was built today:**

Two full feature sessions shipped:

**Session 62 — Harmony tag semantic color** — the "harmony" tag now has its own distinct visual identity across every tag surface in the app. Previously it appeared with a generic gray dot everywhere and was easy to miss. New color is emerald (`#10b981`) — chosen for the "growth, balance, nature" associations of color harmony, and to contrast clearly with rose/trend and sky/shared. Emerald styling now applies to: the main filter-row tag pill (emerald background + text when inactive, emerald-100/700/300 when active), the sidebar tag inventory link, and both the interactive button and static span variants of the palette card tag pill. Introduced `SPECIAL_TAG_STYLES` as a single source of truth for all three special tags' dot color, activeClass, inactiveClass, and sidebarActiveText; `getTagDotColor()` now delegates to it rather than having scattered if-chains. Clean Turbopack build, zero TypeScript errors.

**Session 63 — Special tag pills in the color-search filter strip + Locked badge in info row** — two UX polish improvements:
- When color search is active, the inline filter strip (which already showed mood and locked pills) now also surfaces tag pills for "harmony", "trend", and "shared" — but only for tags that actually appear in the current results, so there are no phantom pills. Pills appear after a `·` dot divider for visual clarity. Each uses the `SPECIAL_TAG_STYLES` color (emerald/rose/sky). Clicking toggles `activeTag` to filter within color-search results; clicking again returns to "all". The implementation uses a generic `["harmony","trend","shared"].filter(...)` pattern so future special tags added to `SPECIAL_TAG_STYLES` automatically appear.
- When a palette is frozen (`palette.frozen === true`), a compact indigo badge (`Lock` icon + "Locked" label) now appears in the info row alongside mood, freshness, and ΔE badges. Makes freeze state scannable across the grid at the same metadata level as other palette properties, complementing the existing swatch-area overlay badge (which can be hard to see against dark palettes) and the name-row lock icon.

Both sessions: clean Turbopack build, zero TypeScript errors, 5 routes passing.
